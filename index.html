Bank matching SOP

  1. Prepare four files for one bank account. Gather the current Chase statement PDF, the ResMan bank register Excel export, the preceding finalized ResMan reconciliation PDF, and the AP Aging Detail Excel export.
  2. Check the date coverage. The register must cover the day after the prior reconciliation through the Chase statement end date. Use an AP Aging snapshot for the same property dated on or after the statement cutoff.
  3. Run the reconciliation. Select the four files in their labeled fields. Keep the combined size under 4 MB and select Run reconciliation.
  4. Review the difference and open items. Compare Chase closing balance with adjusted books balance. Check unmatched items and use the workbook’s Review Candidates tab to verify proposed PayLease groups and same-amount matches.
  5. Save the workbook. Select Download Excel workbook and retain it with the source reports and any unresolved items.
